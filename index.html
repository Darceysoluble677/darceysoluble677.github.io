🎯 What This Software Is

Modern AI assistants can read a photo and then talk about it. But a lot of the time, they answer from memory rather than by genuinely studying the picture. Researchers call this a perception gap. This project gathers the best published techniques for closing that gap and puts them all in one place, so you can compare them without writing research code yourself.

Everything here is organised around two ideas. The first is RLVR, which stands for reinforcement learning with verifiable rewards — a training approach where the model is steered by answers that can be checked automatically, such as a box around the right object. The second is OPD, or on-policy distillation, where a smaller model learns by watching a larger one solve problems step by step.

Instead of hunting down nineteen separate research repositories, each with its own setup quirks, you get a single package that already knows how to run them all and how to score them all. You supply images and questions, press go, and receive clear numbers back.

🖼️ Plain-Words Glossary

  • Vision language model. An AI that can look at a picture and talk about it in ordinary language.
  • RLVR. Training an AI with rewards that a computer can check on its own, so no human has to grade each answer.
  • On-policy distillation. A small model learning by copying the reasoning steps of a bigger one while it works, rather than from a fixed list of answers.
  • Visual grounding. Pointing at the exact part of an image that supports an answer.
  • Benchmark. A standard set of questions with known correct answers, used so that different methods can be compared fairly.
  • Perception-aware score. A check that separates answers the model got right by really looking from answers it got right by guessing.

🛠️ Common Questions

Do I need to install anything else?

No. Everything the software needs is bundled with the download. The first launch prepares the rest automatically.

How long does a typical run take?

A small benchmark with the smallest model usually finishes in five to fifteen minutes. Large benchmarks with a bigger model can take a few hours. You can pause and resume at any time.

The application closed itself on the first launch. What now?

This almost always means the first-time setup was interrupted. Open the application again and leave the window untouched until the setup message disappears. A slow connection can make this stage take several minutes.

Where do my results go?

Every run is saved inside a results folder next to the application. Nothing is uploaded anywhere, and nothing leaves your computer.

Can I add my own images?

Yes. The software accepts a folder of images and a matching question file, then treats it as a new benchmark alongside the built-in ones.
